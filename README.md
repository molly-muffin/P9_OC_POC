# P9 — Proof of Concept: Vision Transformer vs. ResNet-18

**DataSpace Technical Test — OpenClassrooms Data Science Path**

## Project Summary

This proof of concept demonstrates that a Vision Transformer (ViT-B/16, Dosovitskiy et al., 2020) outperforms a classical CNN baseline (ResNet-18, He et al., 2015) on CIFAR-10 image classification.

| Model | Architecture | Year | Expected Accuracy |
|---|---|---|---|
| ResNet-18 | CNN (residual) | 2015 | ~93% |
| ViT-B/16 | Transformer | 2020 | ~96% |

**Reference**: Dosovitskiy et al. (2020) — *An Image is Worth 16x16 Words* — [arXiv:2010.11929](https://arxiv.org/abs/2010.11929)

## Step 1 — Run the Notebook

The notebook trains both models on CIFAR-10 and saves results.

### Option A: Google Colab (recommended — free GPU)

1. Go to [colab.research.google.com](https://colab.research.google.com)
2. Upload `notebook/poc_notebook.ipynb`
3. Set runtime to GPU: `Runtime > Change runtime type > T4 GPU`
4. Run all cells (`Runtime > Run all`)
5. Training takes ~15-20 minutes for 10 epochs with a T4 GPU
6. Download the generated files:
   - `results.json` → place in `dashboard/`
   - `models/resnet18_cifar10.pth` → place in `dashboard/models/`
   - `models/vit_b16_cifar10.pth` → place in `dashboard/models/`

### Option B: Local (requires GPU)

```bash
pip install -r requirements.txt
jupyter notebook notebook/poc_notebook.ipynb
```

## Step 3 — Deploy on Streamlit Community Cloud

1. Push this repository to GitHub (make sure `dashboard/results.json` is included)
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub
3. Click **New app**
4. Select your repository
5. Set **Main file path** to `dashboard/app.py`
6. Click **Deploy**

The app will be live at `https://<your-app-name>.streamlit.app`.

**Important for deployment**: Model weights (`*.pth` files) are large (hundreds of MB).
The Live Demo tab uses models downloaded at runtime via `timm` and `torchvision`,
so no weight files are needed for deployment. The Training Results tab only needs
`results.json` (a small JSON file).

## Key Technical Choices

**Why CIFAR-10?**
Standard benchmark, freely available, balanced across 10 classes, small enough to
train in reasonable time, large enough to show meaningful differences between models.

**Why ResNet-18 as baseline?**
Published in 2015, it is the canonical CNN baseline for image classification.
It represents the state of the art before the Transformer revolution in vision.

**Why ViT-B/16?**
- Published October 2020 → qualifies as recent (<5 years)
- Referenced on arXiv (arXiv:2010.11929), ICLR 2021, cited 30,000+ times
- Represents the paradigm shift from CNNs to Transformers in computer vision
- The "B" (Base) variant balances capability and training cost

**Why fine-tuning from ImageNet?**
ViT requires very large datasets to train from scratch. Fine-tuning from
ImageNet-pretrained weights is the standard production approach and matches
how the method is presented in the original paper.
